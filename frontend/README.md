# 二手商品交易市场前端

## 项目概述
这是一个基于Vue 3 + Element Plus的二手商品交易市场前端应用，采用现代化的前端技术栈和开发流程。

## 技术栈
- **框架**: Vue 3 (Composition API)
- **UI库**: Element Plus
- **路由**: Vue Router 4
- **状态管理**: Pinia
- **HTTP客户端**: Axios
- **构建工具**: Vite

## 开发流程
本项目采用三轮开发模式进行前端页面开发：

### 第1轮：基础页面开发
- 创建基础页面结构和UI布局
- 实现表单基础功能
- 添加基础样式和响应式设计

### 第2轮：交互优化
- 增加组件间联动效果
- 优化表单校验逻辑
- 添加loading状态和用户反馈
- 完善页面跳转逻辑

### 第3轮：联调修复
- 对接后端API接口
- 调整数据格式以匹配后端要求
- 添加错误处理和状态管理
- 优化用户体验和性能

## 主要功能模块

### 1. 商品发布页面 (`ProductPublish.vue`)
- **基础功能**: 商品标题、描述、分类、价格、成色选择
- **交易方式**: 线上/线下交易切换
- **联动效果**: 线下交易显示地址输入框
- **表单校验**: 根据交易方式动态校验地址必填
- **提交功能**: 包含loading状态和成功跳转

### 2. API接口层
- **请求工具**: `utils/request.js` - 统一HTTP请求处理
- **产品接口**: `api/product.js` - 商品相关API
- **认证工具**: `utils/auth.js` - 用户认证相关功能

### 3. 路由配置
- 首页 (`/`)
- 商品发布页 (`/publish`)

## 开发特点

### 1. 组件化设计
- 使用Vue 3 Composition API进行组件开发
- 组件职责单一，可复用性高
- 采用scoped样式避免样式污染

### 2. 响应式设计
- 支持PC端和移动端
- 使用CSS媒体查询适配不同屏幕尺寸
- Element Plus组件自带响应式特性

### 3. 表单校验
- 基于Element Plus的表单校验
- 支持动态校验规则
- 联动校验（如交易方式切换时地址校验）

### 4. API集成
- 统一的HTTP请求封装
- 自动错误处理和用户提示
- Token认证支持
- 请求/响应拦截器

### 5. 状态管理
- 用户认证状态管理
- API调用状态管理
- 组件内部状态管理

## 联调说明
前端开发严格遵循三轮模式：
1. **基础版**: 优先实现UI和基础功能
2. **交互优化**: 增强用户体验和交互逻辑
3. **联调修复**: 根据后端API调整和优化

每次联调都需要检查：
- 数据格式是否匹配后端要求
- 错误处理是否完善
- 用户反馈是否清晰
- 性能是否达标

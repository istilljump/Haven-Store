## 六、遗留项（我没动，需要你决定）

1. **本地数据库名不一致**：你本机现有的是 `second_hand_market`（且只有 3 张表，没有 `system_message`），
   而代码现在指向 `secondhand_market`。本地跑之前需要执行：
   ```bash
   mysql -uroot -p1234 < backend/scripts/01-schema.sql
   ```
   > 该脚本含 `DROP TABLE`，但作用域只在 `secondhand_market` 这个新库里，不会碰你原来的 `second_hand_market`。

2. **管理后台登录接口缺失**：前端 `adminApi.adminLogin()` 请求 `POST /admin/login`，
   但后端 `AdminController` 里没有这个接口（只有 `/admin/stats`、`/admin/users` 等），
   且 `user` 表没有角色字段，无法区分管理员。这块要么补接口、要么让管理后台复用 `/user/login`——
   属于功能设计问题，需要你确认想怎么做。

3. **`application-dev.properties` 指向 H2，但 `pom.xml` 没有 H2 依赖**，该 profile 实际不可用（也不影响默认启动）。

4. **`nginx/nginx.conf` 现在没人用了**（nginx 服务已移除）。可保留备查，也可删除。

5. **仓库里仍有不该公开的文件**：`.zcode/plans/plan-sess_*.md`（AI 开发计划）。
   删除方式：`git rm -r --cached .zcode`

6. 前端单包 1.27MB，构建有 chunk 过大警告，不影响运行，后续可用路由懒加载优化。

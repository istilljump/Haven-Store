## 四、幂等与回滚

- **幂等**：迁移每步先检查「源存在且目标不存在」才执行，重复运行自动跳过。
- **回滚**（改动提交前）：在仓库根目录执行
  ```bash
  bash scripts/undo-restructure.sh
  ```
  脚本会反向 `git mv`、对 8 个被编辑文件执行 `git checkout --` 还原内容、移回 3 个未跟踪压测报告，并删除本清单与自身。执行前请确认那 8 个文件中没有你想保留的其他未提交修改。
- **已提交后回滚**：直接对本次重构的提交执行 `git revert <commit>`。
- 未使用 `git reset --hard`（工作区存在无关的未提交改动，必须保留）。

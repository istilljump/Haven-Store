# 011 · 项目定位重塑方案与交付记录（2026-11）

> 一句话：把「什么都有的小淘宝」重塑为「校园闲置循环平台 × 数据驱动定价」——
> 定位收窄解决「体量宽泛」，成交行情估价解决「缺少专属亮点」。

## 一、反馈与诊断

评审反馈：**项目看起来是普通电商平台，体量宽泛，缺少项目专属亮点。**

摸底诊断（详见会话记录）：

| # | 现象 | 证据 |
| --- | --- | --- |
| 1 | 定位是品类堆砌 | 46 件演示商品横跨 8 品类，像缩小版淘宝 |
| 2 | 招牌功能停在占位 | `ProductAIServiceImpl` 自述"规则引擎占位符"+ ±200 随机抖动 |
| 3 | LBS 只有开关没有场景 | 列表页一个"附近"按钮，演示数据是北上广深通勤坐标 |
| 4 | 品牌无记忆点 | Haven-Store / "二手商品交易市场" / com.example 三者互不相认 |
| 5 | 叙事是功能清单 | README 按"平台有什么"组织，硬货埋在中后段 |

## 二、定位声明（定稿）

> **Haven-Store · 闲置港湾**：面向校园与同城的闲置循环平台——
> 用平台真实成交行情帮卖家定对价，用校区与安全面交点让线下交易更省心。

- **口号**：毕业不甩卖，闲置有归宿。
- **品牌**：保留仓库名 Haven-Store，新增中文副品牌「闲置港湾」（Haven 本义即港湾，中英互文，零迁移成本）。
- **三层功能地图**：招牌层（数据驱动定价、校园 LBS）/ 支撑层（商品级私信、已验证购买、举报闭环、订单状态机）/ 降级层（模拟支付改叙"线上锁货、线下面交"，泛品类收敛展示）。

## 三、本轮落地内容（M1~M4 全部完成）

### M1 定位与品牌落地（文档/叙事）
- 中文副品牌「闲置港湾 Haven-Store」+ 口号，落地到 README、首页 Hero、登录页、页面标题、站点设置默认值
- `SystemSettingDTO.defaults()` 站点名/描述换新文案；`03-upgrade.sql` 幂等同步老库设置

### M2 数据驱动定价（招牌①）
- 新增独立模块 `com.example.market`：`MarketDataMapper`（order_item 快照 × 已支付/已完成订单 × product 分类成色的聚合查询）、`MarketDataService`（中位价/区间/样本量 + 价格分位）、`GET /market/summary`（游客可用）
- **估价双路径**：`MARKET_DATA`（同类成交中位价，依据可解释）→ 样本不足降级 `RULE_BASELINE`（原规则引擎，明示"数据积累中"）；**移除 ±200 随机抖动，同输入必同输出**
- `ProductEstimateVO` 新增 `basisType/sampleSize/marketMedian/marketMin/marketMax/reasons`
- 买家侧**划算指数**：详情页返回 `pricePosition`（低于近期 X% 成交价）与 `marketBasis`
- 卖家侧**降价建议**：「我的发布」对滞销商品（挂牌超 staleDays 天且价格高于行情九折）给出建议价（中位价 × 0.9 向下取整）+ 依据；新增 `POST /product/{id}/price` 一键改价（仅卖家、仅在售）

### M3 校园 LBS 场景化（招牌②）
- 新增独立模块 `com.example.campus`：`campus`（校区 + 中心坐标）、`meet_point`（安全面交点）两张表与 `GET /campus/list`、`GET /campus/{id}/meet-points`、`GET /campus/nearest-meet-point`（Haversine 球面距离，游客可用）
- `product.campus_id` 列 + 发布/编辑校验 + 详情页校区名 + 列表页校区筛选（`/product/search?campusId=`）
- 发布向导新增"所属校区"选择；详情页推荐"距商品最近的安全面交点"

### M4 数据与回归
- `01-schema.sql`：14 张表；种子新增校区×2、面交点×5、**历史成交 15 件**（手机数码·九成新 5 件中位价 3600 / 图书教材·八成新 4 件中位价 25 / 电脑办公·九成新 3 件中位价 220 / 运动户外·八成新 3 件中位价 65）、滞销演示商品 1 件（挂牌 20 天、定价 45 → 建议价 22）
- `03-upgrade.sql`：老库幂等升级（information_schema 判空加列、标题/单号存在即跳过、JSON_VALID 守卫的品牌同步）
- 进阶功能全部做成**后台可开关**：`trade.marketBasis / dealBadge / priceSuggest / staleDays / minSampleSize`（管理后台「交易设置」可视化，缺省开启，老配置缺字段按缺省处理）

## ③ 修复"管理后台登录后不跳转"

### 更正：不需要实测，根因已找到 `[已核实]`
`layouts/AdminLayout.vue` 读 localStorage 用的是 `'userInfo'`，而 `utils/auth.js:11` 定义的写入 key 是 `'user_info'`：

```
utils/auth.js:11        const USER_INFO_KEY = 'user_info'      ← 写入用这个
AdminLayout.vue:181     localStorage.getItem('userInfo')       ← 读的是这个（多下划线，永远 null）
AdminLayout.vue:221,228,236,272,278                             ← 同一个错误共 6 处
```

守卫 `AdminLayout.vue:266-294` 的逻辑是"读不到 userInfo 就 `next('/admin/login')`"。**所以登录成功后一进后台就被弹回登录页**——这就是"不跳转"的现象。v1 说"代码里跳 `/admin/dashboard` 这个路由存在所以不能靠读代码下结论"，这点是对的（路由确实存在），但真正的断点在 key 不一致，不在跳转。

### v1 提到的两个死链，已确认
- `AdminDashboard.vue:324` `/admin/stats` → 不存在
- `AdminDashboard.vue:328` `/admin/logout` → 不存在（应改为调用登出逻辑，路由里根本没有 logout 页）
- 另外 `AdminLayout.vue` 里还有 4 个侧边菜单死链（见 ① 表格）

### 另外 4 个相关缺陷（v1 未提）
1. **`AdminLayout.vue` 缺 `ElMessageBox` 导入**（用了但没 import，第 213 行）→ 点"退出登录"直接 `ReferenceError`。
2. **`router/index.js:64-68` 的 `beforeEach` 只设置标题，没有任何权限守卫** → 未登录也能直接访问 `/admin/dashboard`（页面能开，只是接口返回 401）。v1 要求的"给 `/admin/**` 补路由守卫"确实需要做，而且现在**完全没有**。
3. **`AdminDashboard.vue` 调的 `GET /admin/dashboard` 后端不存在**——后端只有 `GET /admin/stats`（`AdminController.java:77`）。且响应结构也不匹配：前端要 `statistics.{totalUsers,totalProducts,todayProducts,activeUsers}` + `recentProducts` + `systemMessages`，后端返回的是**扁平**的 `{totalUsers, activeUsers, totalProducts, activeProducts}`，没有 `statistics` 包装层、没有 `todayProducts`、没有最近商品/消息。**概览页 4 个数字现在全是 0。**
4. `AdminDashboard.vue:138` 的 `product.price.toFixed(2)`：如果 price 为 null 或是字符串会抛错（后端返回类型待确认）。

### 建议改法
统一 key 常量（`utils/auth.js` 导出 `USER_INFO_KEY`，其它文件一律引用它，不再硬编码字符串）+ 补齐守卫（未登录 → `/admin/login`；非管理员 → 拒绝；已登录访问 `/admin/login` → 自动进后台）+ 补 `ElMessageBox` 导入 + 后端补 `/admin/dashboard`（或把前端改成调 `/admin/stats` 并把返回结构对齐）。

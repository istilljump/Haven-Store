## 二、核心根因：管理后台登录后被打回登录页

原代码里 `AdminLayout.vue` 与 `utils/auth.js` 对 localStorage 的 key 理解不一致：

```
utils/auth.js:11       const USER_INFO_KEY = 'user_info'   ← 登录成功时写入这个 key
AdminLayout.vue:181    localStorage.getItem('userInfo')    ← 守卫读的是这个 key（多一个下划线）
```

守卫逻辑是「读不到用户信息就跳回登录页」，因此**登录成功 → 一进后台立刻被弹回登录页**。

**修复**：`AdminLayout.vue` 改为统一使用 `utils/auth` 的 `getUserInfo()`，
并把 `/admin/**` 的权限校验从组件内（每次挂载都重复注册守卫）收敛到 `router/index.js` 的全局守卫，一处生效。

## 六、如何运行

```bash
# 前置：MySQL 与 Redis 必须已启动（登录会把用户信息写入 Redis）

# 1. 数据库（已有库执行增量语句，见第 3.4 节；新库直接执行脚本）
mysql -uroot -p < backend/scripts/01-schema.sql

# 2. 后端（默认 8080，上下文路径 /api）
cd backend
mvn spring-boot:run
# 或打包运行：mvn -Dmaven.test.skip=true package && java -jar target/second-hand-market-1.0.0.jar

# 3. 前端（默认 3000，已配置 /api 代理到 8080）
cd frontend
npm install
npm run dev

# 4. 接口冒烟（可选）
python tests/api_smoke_test.py
```

访问入口：首页 <http://localhost:3000/home>，管理后台 <http://localhost:3000/admin>，
接口文档 <http://localhost:8080/api/doc.html>

默认账号：`admin` / `admin123`（管理员）、`testuser1` / `123456`（普通用户）
